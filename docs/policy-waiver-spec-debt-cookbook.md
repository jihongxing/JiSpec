The maintained guide still covers `policy migrate`, waiver management, release compare, and Console follow-up.

Use `policy migrate` to create or normalize policy.
Use `waiver create` and `waiver revoke` for waiver lifecycle control.
Use `waiver renew` when a waiver needs to stay explicit for longer.
Use `spec-debt repay` and `spec-debt owner-review` when contract debt needs closure.
Use `release snapshot` before `release compare` when you want a stable baseline.
Use `release compare` and `console actions` to review release hygiene and governance follow-up.

# JiSpec Takeover Guide

This page moved to [user-guide/takeover-guide.md](./user-guide/takeover-guide.md).

Use the new location for the maintained takeover decision guidance.
This compatibility page stays here so older links do not break immediately.

The maintained guide still explains when to `accept`, `edit`, `defer`, or `reject` a draft.

Use `accept` when the draft is clearly supported.
Use `edit` when the wording needs owner refinement.
Use `defer` when the evidence should become spec debt.
Use `reject` when the draft over-claims or lacks support.
`verify` remains the deterministic local gate.
